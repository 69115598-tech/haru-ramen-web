# Haru Ramen — ระบบสั่งอาหาร QR / ครัว / POS / แอดมิน

เว็บสั่งอาหารผ่าน QR Code สำหรับร้านราเมง ประกอบด้วยหน้าลูกค้า หน้าจอครัว (KDS) POS และหลังร้าน
โฮสต์ฟรีบน **GitHub Pages** เก็บข้อมูลบน **Supabase**

## ไฟล์ในโปรเจกต์ (อัปโหลดทุกไฟล์ไว้ "ระดับบนสุด" ของ repo ไม่ต้องสร้างโฟลเดอร์)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปทั้งหมด (หน้าลูกค้า ครัว POS แอดมิน) |
| `config.js` | **ไฟล์ที่ต้องแก้** ใส่ URL และ anon key ของ Supabase |
| `supabase-shim.js` | ตัวเชื่อมแอปกับ Supabase (ไม่ต้องแก้) |
| `supabase-setup.sql` | สคริปต์สร้างตารางฐานข้อมูล (รันครั้งเดียวใน Supabase) |
| `README.md` | คู่มือนี้ |

## ขั้นตอนที่ 1 ตั้งค่าฐานข้อมูล (Supabase)
1. เข้า https://supabase.com สมัคร/ล็อกอิน แล้วกด **New project** (เลือก Region: Singapore) ตั้งรหัสผ่านฐานข้อมูลเก็บไว้
2. รอโปรเจกต์สร้างเสร็จ ไปที่เมนูซ้าย **SQL Editor** → **New query**
3. เปิดไฟล์ `supabase-setup.sql` คัดลอกทั้งหมดไปวาง แล้วกด **Run** (ต้องขึ้น Success)
4. ไปที่ **Project Settings → API** คัดลอก 2 ค่า
   - **Project URL** (เช่น `https://abcd1234.supabase.co`)
   - **anon public** key
5. เปิด `config.js` แทนที่ `YOUR-PROJECT-ID...` และ `YOUR-ANON-PUBLIC-KEY` ด้วย 2 ค่านั้น แล้วบันทึก
   - ห้ามใช้ `service_role` key ในไฟล์นี้เด็ดขาด (anon key ออกแบบมาให้อยู่ฝั่งหน้าเว็บได้ ส่วน service_role คือกุญแจลับ)

## ขั้นตอนที่ 2 นำขึ้น GitHub Pages
1. เข้า https://github.com สมัคร/ล็อกอิน → **New repository**
   - ชื่อ `haru-ramen` · เลือก **Public** · กด Create repository
2. กด **uploading an existing file** (หรือ Add file → Upload files) ลากไฟล์ทั้ง 5 ไฟล์ใส่ → **Commit changes**
   - ตรวจว่า `index.html` อยู่ระดับบนสุด ไม่อยู่ในโฟลเดอร์ย่อย
3. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** · Folder: **/(root)** → กด **Save**
4. รอ 1–2 นาที รีเฟรชหน้า Pages จะแสดงลิงก์ เช่น `https://USERNAME.github.io/haru-ramen/`
   - ไฟล์ทั้งหมดอ้างอิงแบบ relative path (`config.js`, `supabase-shim.js`) จึงไม่มีปัญหา base path ใน repo ที่ชื่อ `haru-ramen`

## ขั้นตอนที่ 3 เริ่มใช้งานครั้งแรก
1. เปิดลิงก์เว็บ แล้วต่อท้ายด้วย `#admin` เช่น `https://USERNAME.github.io/haru-ramen/#admin`
2. ล็อกอิน `admin / admin123`
3. แท็บ **จัดการเมนู** → กดปุ่ม **บันทึกเข้าฐานข้อมูล** 1 ครั้ง (เพื่อสร้างเมนูตัวอย่าง 31 รายการ)
4. แท็บ **โต๊ะ/QR Code** → ตรวจว่าช่องลิงก์เป็นลิงก์ GitHub Pages ของคุณ → ดาวน์โหลด PNG ของ QR กลางร้านและโต๊ะ T01–T05 หรือกด **พิมพ์ทั้งหมด**
5. แท็บ **จัดการเมนู → แก้ไข** เลือกไฟล์รูปเพื่อใส่รูปอาหาร (รูปเก็บบน Supabase Storage)

## วิธีที่ลูกค้าและทีมใช้งาน
| ใคร | ลิงก์ |
|---|---|
| ลูกค้านั่งโต๊ะ | สแกน QR → `…/haru-ramen/#T03` (ระบุโต๊ะอัตโนมัติ) |
| ลูกค้าทั่วไป | `…/haru-ramen/` |
| ครัว | `…/haru-ramen/#kitchen` (ล็อกอิน `staff / staff123`) |
| POS | `…/haru-ramen/#pos` |
| แอดมิน | `…/haru-ramen/#admin` |

รองรับรูปแบบ `?table=T01` ด้วย เช่น `…/haru-ramen/?table=T01`

**บัญชีทดลอง:** `admin / admin123` · `staff / staff123` · `chef / chef123`

## ทดสอบระบบก่อนส่งงาน
1. เปิดเว็บผ่านลิงก์บนคอมและมือถือ
2. สแกน QR โต๊ะ ดูว่าขึ้น "โต๊ะ T0X" ถูกต้อง
3. สั่งอาหาร → ออเดอร์ต้องขึ้นในหน้าครัวและแอดมิน (เปิดอีกเครื่องดู)
4. ครัวกดเปลี่ยนสถานะ → หน้าออเดอร์ของลูกค้าอัปเดต
5. แอดมินปิดขายเมนู → หน้าลูกค้าขึ้น "หมด"
6. POS ใส่ส่วนลด ชำระเงิน ดูใบเสร็จ (มี VAT 7% รวมในราคา)
7. ปุ่ม **จำลองออเดอร์** ใช้สร้างออเดอร์ปลอมให้เห็นการทำงาน กด **ล้างข้อมูลจำลอง** ก่อนใช้งานจริง

## ข้อจำกัดสำคัญ (โปรดอ่าน)
- **ความปลอดภัยเป็นแบบทดลอง:** ระบบล็อกอินอยู่ฝั่งหน้าเว็บ และสิทธิ์ฐานข้อมูลเปิดให้ทุกคนอ่าน/เขียนได้ เหมาะกับการนำเสนอและทดสอบเท่านั้น
  ถ้าจะใช้จริง ต้องเปลี่ยนเป็น Supabase Auth และเขียนนโยบาย (RLS) แยกสิทธิ์ลูกค้า/พนักงาน/แอดมิน
- **รูปอาหาร:** ต้องอัปโหลดเอง (ระบบไม่มีรูปมาให้)
- **ราคาเมนูแก้ในแอดมินได้** แต่ต้นแบบเมนูเริ่มต้นฝังอยู่ใน `index.html`
- เปลี่ยนชื่อ repo หรือย้ายลิงก์ → เข้าแอดมิน → โต๊ะ/QR Code → แก้ลิงก์ แล้วกด **สร้างใหม่** จากนั้นพิมพ์ QR ใหม่
